Transformers are modern neural network architectures designed for sequential data processing.
The Transformer model was introduced in the landmark paper titled Attention Is All You Need.
Unlike recurrent neural networks the Transformer processes all input tokens in parallel.
Parallel processing allows Transformers to train much faster on modern hardware accelerators.
The central innovation of the Transformer is the self attention mechanism.
Self attention allows each token in a sequence to dynamically attend to all other tokens.
The attention mechanism calculates relevance scores between pairs of tokens.
Scaled dot product attention uses query key and value vectors.
The query vector represents the current token looking for relevant information.
The key vector represents the content and identity of each candidate token.
The value vector holds the actual semantic information to be aggregated.
Attention scores are computed by taking the dot product of queries and keys.
The dot products are divided by the square root of the key dimension for numerical stability.
Softmax is applied to normalize the attention scores into a valid probability distribution.
The resulting attention weights sum to one across all evaluated key positions.
The output of self attention is a weighted sum of the value vectors.
Causal self attention uses an upper triangular mask to prevent looking into the future.
Causal masking is essential for next token prediction and autoregressive language modeling.
Without causal masking a language model would simply cheat by copying future tokens.
Multi head attention runs several attention mechanisms in parallel with different linear projections.
Each attention head can learn to focus on different types of linguistic relationships.
One head might track grammatical agreement while another head tracks semantic dependencies.
Positional encoding provides the model with information about the order of tokens in the sequence.
Because self attention is permutation invariant positional information is strictly necessary.
Learnable positional embeddings assign a trained vector representation to each sequence index.
Residual connections add the input of a sublayer directly to its output.
Residual connections allow gradients to flow smoothly through deep networks during backpropagation.
Layer normalization stabilizes training dynamics by normalizing activations across the feature dimension.
The feed forward network applies two linear transformations with a non linear activation function.
GELU and ReLU are popular activation functions used in Transformer feed forward sublayers.
Autoregressive language models predict the next token given all preceding context tokens.
Greedy decoding always selects the token with the highest predicted probability.
Sampling selects the next token probabilistically according to the model output distribution.
Temperature scaling adjusts the sharpness of the probability distribution during text generation.
A lower temperature makes generation more confident and deterministic.
A higher temperature increases randomness and stylistic diversity.
